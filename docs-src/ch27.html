styled-components

styled-components 是最有名的 CSS-in-JS 库。先安装并导入：

```bash npm install styled-components ``` ```jsx src/App.jsx import axios from 'axios'; import styled from 'styled-components'; ```

用 styled.标签名 加一段模板字符串，就创建出一个“自带样式的组件”：

```jsx src/App.jsx const StyledContainer = styled.div` height: 100vw; padding: 20px; background: #83a4d4; background: linear-gradient(to left, #b6fbff, #83a4d4); color: #171212; `; const StyledHeadlinePrimary = styled.h1` font-size: 48px; font-weight: 300; letter-spacing: 2px; `; ```

根据 props 动态设置样式

Item 里原来用行内样式设置每列宽度。换成一个 StyledColumn，宽度通过 prop 传进去， 在模板字符串里用一个函数读取：

```jsx src/App.jsx const StyledItem = styled.li` display: flex; align-items: center; padding-bottom: 5px; `; const StyledColumn = styled.span` padding: 0 5px; white-space: nowrap; overflow: hidden; text-overflow: ellipsis; a { color: inherit; } width: ${(props) => props.$width}; `; const Item = ({ item, onRemoveItem }) => ( {item.title} {item.author} {item.num_comments} {item.points} onRemoveItem(item)} > Dismiss ); ```
ⓘ 为什么是 $width 而不是 width

原书写的是 width="40%"。styled-components v6 不再自动过滤 props，width 会被原样传到真实的 <span> 上，React 会警告这是个未知的 DOM 属性。以 $ 开头的 transient prop 只给样式使用，不会传到 DOM，这是 v6 推荐的写法。

嵌套与扩展

CSS 嵌套开箱即用，& 表示当前元素。styled(已有组件) 可以在已有样式基础上扩展：

```jsx src/App.jsx const StyledButton = styled.button` background: transparent; border: 1px solid #171212; padding: 5px; cursor: pointer; transition: all 0.1s ease-in; &:hover { background: #171212; color: #ffffff; } `; const StyledButtonSmall = styled(StyledButton)` padding: 5px; `; const StyledButtonLarge = styled(StyledButton)` padding: 10px; `; const StyledSearchForm = styled.form` padding: 10px 0 20px 0; display: flex; align-items: baseline; `; const StyledLabel = styled.label` border-top: 1px solid #171212; border-left: 1px solid #171212; padding-left: 5px; font-size: 24px; `; const StyledInput = styled.input` border: none; border-bottom: 1px solid #171212; background-color: transparent; font-size: 24px; `; ```

styled 组件渲染的仍然是真实的 HTML 元素，所以原生属性（action、type、disabled、ref）照常可用：

```jsx src/App.jsx const SearchForm = ({ searchTerm, onSearchInput, searchAction }) => ( Search: Submit ); const InputWithLabel = ({ ... }) => { ... return ( <> {children}   ); }; ```
⚠ CSS-in-JS 的现状（2025 年起）

styled-components 这类运行时 CSS-in-JS 库在浏览器里生成样式，会带来额外开销，并且与 React 服务端组件配合不佳。 2025 年 styled-components 已宣布进入维护模式，不再开发新功能，官方也不建议新项目采用。 你仍会在大量现有项目里见到它，所以值得了解；但新项目更推荐 CSS Modules、Tailwind，或“零运行时”的 CSS-in-JS（如 vanilla-extract、Linaria），它们在构建时把样式提取成普通 CSS 文件。

另一种思路：Tailwind CSS

Tailwind 属于 utility-first 流派：不写 CSS 类名，而是直接在 className 里组合大量“一个类只做一件事”的工具类。 在 Vite 项目中安装：

```bash npm install tailwindcss @tailwindcss/vite ``` ```js vite.config.js import { defineConfig } from 'vite'; import react from '@vitejs/plugin-react'; import tailwindcss from '@tailwindcss/vite'; export default defineConfig({ plugins: [react(), tailwindcss()], }); ``` ```css src/index.css @import "tailwindcss"; ```

    SVG 图标

    现代界面大量使用 SVG 图标。这一节在“普通 CSS”方案的基础上，把 “Dismiss” 文字换成一个对勾图标。 在 React 里使用 SVG 有三种常见方式：

    安装 Vite 的 SVG 插件并加入配置：

    ```bash npm install vite-plugin-svgr --save-dev ``` ```js vite.config.js import { defineConfig } from 'vite'; import react from '@vitejs/plugin-react'; import svgr from 'vite-plugin-svgr'; export default defineConfig({ plugins: [react(), svgr()], }); ```

    ```html src/check.svg ```

    在导入路径后加 ?react，得到的就是一个 React 组件：

    ```jsx src/App.jsx import './App.css'; import Check from './check.svg?react'; const Item = ({ item, onRemoveItem }) => (
  • ...
    • ); ```

    SVG 里的 stroke="currentColor" 让图标使用当前文字颜色，所以按钮 hover 时文字变白，图标也跟着变白。

    ⓘ 可访问性

    按钮只剩下图标后，读屏软件就不知道它是干什么的了。给按钮加上 aria-label="Dismiss"， 或者在图标旁放一个视觉上隐藏的文字。第 30 章用 React Testing Library 按角色和名字查找按钮时，也会依赖这一点。

    小结

    • styled-components：styled.div`…` 创建带样式的组件，模板字符串里用函数读取 props，用 $ 开头的 transient prop 避免传到 DOM。
    • 运行时 CSS-in-JS 已不再是新项目的首选（styled-components 进入维护模式）；Tailwind 和零运行时方案更流行。
    • SVG 可以当图片、当组件（vite-plugin-svgr + ?react）、或用图标库；当组件时可以继承颜色、接收 props。

    动手练习

    1. styled-components 没有全局 CSS 文件，查一查怎么用 createGlobalStyle 定义全局样式。
    2. 试用一次 Tailwind：新建一个分支，把 Item 改成 Tailwind 类名。
    3. 安装 react-icons，把对勾换成一个垃圾桶图标，并给按钮加上 aria-label。

    面试题

    什么是 CSS-in-JS？有什么优缺点？

    在 JavaScript 中编写样式并与组件绑定。优点：作用域隔离、基于 props 的动态样式、样式与组件共存；缺点：运行时开销、与服务端组件兼容性差、增加包体积（零运行时方案可缓解）。

    styled-components 中如何根据 props 改变样式？

    在模板字符串中插入函数：${(props) => props.$width}；v6 中建议使用 $ 前缀的 transient props，避免属性被传到 DOM。

    在 React 中使用 SVG 有哪些方式？

    作为 img 的 src、内联 JSX、通过 svgr 转换成组件、或使用图标组件库。

    Tailwind CSS 的核心思路是什么？

    utility-first：用大量单一用途的工具类直接在 className 中组合样式，构建时只生成用到的 CSS。
