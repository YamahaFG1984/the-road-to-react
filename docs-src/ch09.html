现在 list 是一个全局变量，谁都能直接用。这在一个文件、一个组件时还凑合， 组件一多、分散到不同文件里就行不通了。React 给组件之间传递数据的方式叫 props： 就像给 HTML 标签写属性一样，给组件写属性。

本章目标

  • 用 props 把数据从父组件传给子组件
  • 理解 props 就是组件函数的第一个参数 —— 一个对象
  • 提取出 Item 组件，完成上一章留下的练习
  • 记住 props 是只读的，数据只能从上往下流
  • 知道 PropTypes 在 React 19 中已经不再生效

先把数据搬进 App

把全局的 list 挪进 App 组件内部，并改个更有意义的名字 stories。 别忘了 App 要从简洁体改回块体：

```jsx src/App.jsx const App = () => { const stories = [ { title: 'React', url: 'https://react.dev/', author: 'Jordan Walke', num_comments: 3, points: 4, objectID: 0, }, { title: 'Redux', url: 'https://redux.js.org/', author: 'Dan Abramov, Andrew Clark', num_comments: 2, points: 5, objectID: 1, }, ]; return ( ... ); }; ```

现在 List 组件访问不到 stories 了 —— 它是 App 函数里的局部变量。 这正是我们要解决的问题。

这就是 props（properties 的缩写）的全部机制。你已经成功地把数据从一个组件传到了另一个组件。 现在回头看第 6 章的思考题：两个 <List list={a} /> 和 <List list={b} /> 就能显示不同的数据了。

    注意 key 现在写在 <Item> 上 —— key 要放在 map() 直接返回的那个元素上， 而不是 Item 组件内部的 <li> 上。

    props 是只读的

    ★ 关于 props 最重要的一条规则

    组件绝不能修改自己的 props。props 是父组件交给你的数据，就像函数参数一样， 只能读、不能写。写 props.item.title = 'x' 这样的代码，是 React 里的大忌： 它会让数据的来源变得混乱，界面也不会因此更新。

    同时，props 只能从父组件流向子组件，反过来不行。那子组件想“告诉”父组件点什么怎么办？ 比如 Search 想把用户输入的内容交给 App 去过滤列表？第 11 章揭晓。

    关于 PropTypes 和 ESLint 警告

    如果你的项目启用了 eslint-plugin-react，可能会看到这样的提示： “'list' is missing in props validation”。它希望你用 PropTypes 声明每个 prop 的类型。 但在今天，这条规则已经不值得遵守了：

    PropTypes 运行时检查 React 19 中不再生效
    ```jsx import PropTypes from 'prop-types'; const List = (props) => ( ... ); List.propTypes = { list: PropTypes.array.isRequired, }; List.defaultProps = { list: [], }; ```
    TypeScript 编译期检查 推荐
    ```tsx type ListProps = { list: Story[]; }; // 默认值直接用参数默认值 const List = ({ list = [] }: ListProps) => ( ... ); ```

    React 19 已经移除了 propTypes 的检查（写了也会被静默忽略）， 也移除了函数组件的 defaultProps（改用 ES6 参数默认值，第 13 章会讲）。 类型检查交给 TypeScript（第 29 章）。如果 ESLint 报这个错，在 eslint.config.js 里关掉这条规则即可：

    ```js eslint.config.js rules: { // ... 'react/prop-types': 'off', }, ```

    小结

    • 在组件元素上写属性 <List list={stories} />，子组件通过第一个参数 props 读取：props.list。
    • props 可以是任何值：字符串、数组、对象、函数、JSX。
    • 在 map() 里给子组件传 item，就能拆出 Item 这样的“单项组件”；key 写在 map 返回的元素上。
    • props 只读，只能从父到子单向流动。
    • PropTypes / defaultProps 是旧的做法，React 19 中已失效；用 TypeScript 和参数默认值代替。

    面试题

    什么是 props？

    props（properties）是父组件传给子组件的数据，子组件以函数参数（一个对象）的形式接收。

    子组件能修改 props 吗？

    不能。props 应被视为只读（不可变）的数据；要改变数据，应由拥有该数据的组件通过 state 修改。

    什么是单向数据流？

    数据只能沿组件树自上而下通过 props 传递。子组件想影响父组件，需要父组件传下一个回调函数。

    React 19 中 propTypes 和 defaultProps 有什么变化？

    propTypes 检查被移除（被静默忽略）；函数组件的 defaultProps 被移除，应改用 ES6 默认参数。推荐用 TypeScript 做类型检查。
