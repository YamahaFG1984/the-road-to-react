客户端组件与 'use client'

服务端组件不能有交互：不能用 useState、useEffect、onClick（它们只在服务器运行一次）。 需要交互的组件，在文件顶部写 'use client'，标记为客户端组件：

```tsx app/search-form.tsx 'use client'; import { useRouter } from 'next/navigation'; import { useState } from 'react'; export function SearchForm({ defaultValue }: { defaultValue: string }) { const [searchTerm, setSearchTerm] = useState(defaultValue); const router = useRouter(); return (

★ 边界规则
  • 'use client' 标记的是一个边界：这个文件，以及它导入的所有组件，都会成为客户端组件。
  • 服务端组件可以渲染客户端组件，并通过 props 传数据（数据必须能序列化：不能传函数，除非是服务端函数）。
  • 客户端组件不能直接 import 服务端组件，但可以通过 children 接收服务端组件渲染好的内容（第 16 章的组合）。
  • 原则：让 'use client' 尽量靠近叶子节点，只把真正需要交互的部分放到客户端。
ⓘ 客户端组件也会在服务器上渲染一次

名字容易误导：客户端组件也会参与服务端渲染（SSR）生成首屏 HTML，然后在浏览器里“激活”（hydrate）变得可交互。 区别在于：服务端组件只在服务器运行，它的代码永远不会发送到浏览器。

⚠ 服务端函数是公开的接口

任何人都可以直接向服务端函数发请求，不一定经过你的表单。所以永远要在函数内部校验输入（上面的 Zod）和检查权限（用户是否登录、是否有权修改）。 这就是第 41 章说的“服务端校验是为了安全”。

新旧对照：Pages Router

Pages Router Next.js 12 及以前的主流
```jsx // pages/index.jsx export async function getServerSideProps({ query }) { const stories = await fetchStories(query.query ?? 'React'); return { props: { stories } }; } export default function StoriesPage({ stories }) { return ; } // 所有组件都会发送到浏览器 ```
App Router Next.js 13+ / React 19
```tsx // app/page.tsx export default async function StoriesPage({ searchParams }) { const { query = 'React' } = await searchParams; const stories = await fetchStories(query); return ; } // 服务端组件不发送到浏览器 ```

网上大量 Next.js 教程还是 Pages Router 写法（getServerSideProps、getStaticProps、pages/ 目录）。 Pages Router 仍然被支持，但新项目请使用 App Router。另外，Next.js 的缓存策略在最近几个大版本中变化较大， 遇到“数据不更新”之类的问题时，请以你所用版本的官方文档为准。

小结

  • App Router 用文件夹定义路由，layout、page、loading、error、[param] 对应布局、页面、Suspense、错误边界和动态参数。
  • 组件默认是服务端组件：可以 async、直接取数据、访问服务器资源，代码不发送到浏览器。
  • 需要状态和事件的组件加 'use client'，让边界尽量靠近叶子。
  • 服务端函数（'use server'）让表单直接调用服务器逻辑，但要当作公开接口来校验和鉴权。
  • 本教程学到的 React 基础全部适用，框架只是替你组装和扩展了它们。

面试题

服务端组件和客户端组件有什么区别？

服务端组件只在服务器运行，可以直接访问数据和服务器资源，代码不发送到浏览器，但不能使用状态、副作用和事件处理；客户端组件用 'use client' 标记，会被发送到浏览器并可以交互（首屏也会参与 SSR）。

'use client' 的作用范围是什么？

它标记一个模块边界：该文件及其导入的模块都作为客户端代码打包。服务端组件可以渲染客户端组件并传递可序列化的 props。

什么是服务端函数（Server Functions / Server Actions）？

用 'use server' 标记、在服务器上执行的异步函数，可以作为 form action 或在客户端调用；框架自动将其暴露为网络接口，因此必须在内部做输入校验和权限检查。

Next.js App Router 如何处理加载和错误状态？

通过 loading.tsx 和 error.tsx 约定文件，框架自动为对应路由段包裹 Suspense 边界和错误边界。
