解剖一个函数组件

  1. 它就是一个 JavaScript 函数。这种组件叫函数组件（function component）， 是现代 React 的唯一推荐写法。唯一的特殊要求是名字必须大写开头： React 靠首字母区分 <div>（HTML 标签）和 <App />（你的组件）。 写成 function app()，<app /> 会被当成一个不存在的 HTML 标签。
  2. 它可以接收参数。现在 App 没有参数，第 9 章学 props 时， 父组件传来的数据就会作为第一个参数传进来。
  3. 它返回长得像 HTML 的东西。这叫 JSX，下一章专门讲。

渲染 = 调用你的函数

和普通函数一样，组件在 return 之前可以写任何逻辑：

```jsx src/App.jsx function App() { // 这里可以做任何事：定义变量、计算、调用函数…… const title = 'React'; return (

Hello React

); } ```

关键问题是：这个函数什么时候执行？答案是：每次 React 需要知道这个组件长什么样的时候。 组件第一次出现在页面上时执行一次，叫渲染（render）；之后每当它的数据发生变化， React 会再调用一次，叫重新渲染（re-render）。

变量放在组件里面还是外面？

既然函数体每次渲染都会重新执行，定义在里面的 title 也会每次重新创建。 而 title 根本不依赖组件内部的任何东西，完全可以挪到外面，只定义一次：

放在里面：每次渲染都重新定义
```jsx function App() { const title = 'React'; return

Hello React

; } ```
放在外面：只定义一次
```jsx const title = 'React'; function App() { return

Hello React

; } ```
★ 经验法则

如果一个变量（或函数）不需要用到组件内部的任何东西（参数、状态）， 就把它定义在组件外面。需要用到的，才放在组件里面。 整本书你都会反复遇到这两种情况。

导出与导入

文件末尾的 export default App; 把组件导出，main.jsx 才能通过 import App from './App.jsx' 拿到它。这是标准的 JavaScript 模块语法，不是 React 特有的。 一个文件只能有一个 export default，但可以有多个具名导出 export { A, B }， 第 30、32 章会用到。

旧写法：类组件

如果你在老项目或老教程里看到 class App extends React.Component，那是 类组件。 在 2019 年 Hooks 出现之前，只有类组件能拥有状态和生命周期，所以老代码里到处都是它。

类组件 旧写法
```jsx import React from 'react'; class App extends React.Component { render() { return (

Hello React

); } } export default App; ```
函数组件 推荐
```jsx function App() { return (

Hello React

  • 类组件的界面写在 render() 方法里；函数组件直接 return。
  • 类组件要和 this、this.state、this.setState、componentDidMount 打交道；函数组件用 Hooks（useState、useEffect）。
  • 类组件没有被删除，React 19 依然支持，但官方文档已经把它放进 “Legacy API”。新代码一律写函数组件。
ⓘ 关于 import React from 'react'

老代码每个文件开头都有 import React from 'react'，因为以前 JSX 会被编译成 React.createElement(...)，必须有 React 这个变量在作用域里。 React 17 起引入了“新 JSX 转换”，编译器会自动导入需要的函数，只写 JSX 的文件不必再导入 React。 只有用到 useState 等 API 时才需要导入，本教程统一写成 import { useState } from 'react'。

小结

  • React 组件就是一个大写开头、返回 JSX 的 JavaScript 函数。
  • 每次渲染（首次渲染和重新渲染）React 都会调用一次组件函数，函数体从头执行。
  • 不依赖组件内部数据的变量和函数，应当定义在组件外面。
  • 类组件是旧写法；函数组件 + Hooks 是现代 React 的标准。

面试题

为什么组件名必须以大写字母开头？

JSX 通过首字母区分原生 HTML 元素和自定义组件：小写被当作 DOM 标签字符串（如 'div'），大写被当作变量引用（组件函数）。

函数组件每次渲染时会发生什么？

React 会重新调用这个函数，函数体内的变量和函数都会重新创建，返回新的 JSX；React 再将其与上次结果比较，只更新 DOM 中变化的部分。

函数组件和类组件有什么区别？

函数组件是普通函数，用 Hooks 管理状态和副作用，没有 this；类组件继承 React.Component，用 this.state 和生命周期方法。现代 React 推荐函数组件，类组件属于遗留 API。
