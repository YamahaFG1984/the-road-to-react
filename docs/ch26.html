第 26 章 · 样式

CSS 与 CSS Modules

React 本身不关心样式怎么写，所以社区里出现了很多方案，争论也从没停过。 这一章和下一章各介绍几种有代表性的方案。它们是互相替代的路径：读的时候可以都试一遍， 但项目里最终只选一种。先从最基础的普通 CSS开始，再升级到带作用域的 CSS Modules。

本章目标

  • 认识 React 的几大样式策略
  • 用 className + CSS 文件、以及 style 对象给组件加样式
  • 理解全局 CSS 的命名冲突问题，用 CSS Modules 解决它
  • 用 clsx 组合多个类名

样式策略全景

如果不想从零写按钮、对话框、下拉菜单，也可以用现成的 UI 组件库。但学习阶段建议先自己写一遍，再去用库。

全局样式

Vite 已经配置好了 CSS 导入，直接 import 一个 CSS 文件就能生效。src/main.jsx 里本来就导入了 index.css：

src/main.jsx
import { StrictMode } from 'react';
import { createRoot } from 'react-dom/client';
import './index.css';
import App from './App.jsx';

createRoot(document.getElementById('root')).render(
  <StrictMode>
    <App />
  </StrictMode>
);

在 src/index.css 里写全局样式，比如去掉 body 的外边距、统一字体：

src/index.css
body {
  margin: 0;
  font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', 'Roboto',
    'Oxygen', 'Ubuntu', 'Cantarell', 'Fira Sans', 'Droid Sans',
    'Helvetica Neue', sans-serif;
  -webkit-font-smoothing: antialiased;
  -moz-osx-font-smoothing: grayscale;
}

普通 CSS + className

给元素加 className（第 4 章说过，JSX 里不能用 class）：

src/App.jsx
import './App.css';

const App = () => {

行内样式 style

Item 用到另一种写法 —— style 属性。在 JSX 里它是一个 JavaScript 对象（外层花括号表示“这里是 JS”，内层是对象字面量）：

src/App.jsx
const Item = ({ item, onRemoveItem }) => (
  <li className="item">
    <span style={{ width: '40%' }}>
      <a href={item.url}>{item.title}</a>
    </span>
    <span style={{ width: '30%' }}>{item.author}</span>
    <span style={{ width: '10%' }}>{item.num_comments}</span>
    <span style={{ width: '10%' }}>{item.points}</span>
    <span style={{ width: '10%' }}>
      <button
        type="button"
        onClick={() => onRemoveItem(item)}
        className="button button_small"
      >
        Dismiss
      </button>
    </span>
  </li>
);

行内样式适合“由数据动态决定”的值和快速原型，但不宜多用：它让 JSX 变长，也不支持 :hover、媒体查询等。 属性名用驼峰（fontSize），数字值默认单位是 px（{ fontSize: 14 }）。

src/App.css
.item {

  align-items: center;
  padding-bottom: 5px;
}

.item > span {
  padding: 0 5px;
  white-space: nowrap;
  overflow: hidden;
  text-overflow: ellipsis;
}

.item > span > a {
  color: inherit;
}

.button {
  background: transparent;
  border: 1px solid #171212;
  padding: 5px;
  cursor: pointer;

  transition: all 0.1s ease-in;
}

.button:hover {
  background: #171212;
  color: #ffffff;
}

.button_small {
  padding: 5px;
}

.button_large {
  padding: 10px;
}

ⓘ 新旧对照：CSS 嵌套

以前想写 .item { & > span { … } } 这样的嵌套，必须引入 Sass。 从 2023 年起，所有主流浏览器都已原生支持 CSS 嵌套，普通 CSS 文件里也能直接写了。 CSS 变量（--color: …）、:has() 选择器等也都已普及，“不用预处理器”比以前容易得多。

全局 CSS 的问题

普通 CSS 的类名是全局的。组件一多、文件一多，两个人各自写了个 .button， 谁后加载谁就覆盖谁 —— 而且不会有任何报错。

CSS Modules

CSS Modules 的 CSS 写法完全不变，变的是在组件里怎么使用它。Vite 内置支持，只需要把文件名改成 .module.css：

命令行
mv src/App.css src/App.module.css

然后把它作为一个 JavaScript 对象导入（名字随意，惯例叫 styles）：

src/App.jsx
import axios from 'axios';

import styles from './App.module.css';

styles 的每个属性对应一个类名，值是构建时生成的唯一类名：

src/App.jsx
const App = () => {
  ...
  return (
    <div className={styles.container}>
      <h1 className={styles.headlinePrimary}>My Hacker Stories</h1>
      ...
    </div>
  );
};
⚠ 类名改用驼峰

styles.headline-primary 在 JavaScript 里会被解析成减法，styles.button_small 也不美观。 所以 CSS Modules 里的类名一般改用驼峰：.headlinePrimary、.buttonSmall，才能写成 styles.buttonSmall。 否则只能写 styles['headline-primary']。

src/App.module.css
.container { ... }

.headlinePrimary {
  font-size: 48px;
  font-weight: 300;
  letter-spacing: 2px;
}

.item { ... }
.item > span { ... }
.item > span > a { ... }

.button { ... }
.button:hover { ... }

.buttonSmall {
  padding: 5px;
}

.buttonLarge {
  padding: 10px;
}

.searchForm { ... }
.label { ... }
.input { ... }

组合多个类名

一个元素要同时使用两个类时，用模板字符串拼起来：

src/App.jsx
const Item = ({ item, onRemoveItem }) => (
  <li className={styles.item}>
    ...
    <span style={{ width: '10%' }}>
      <button
        type="button"
        onClick={() => onRemoveItem(item)}
        className={`${styles.button} ${styles.buttonSmall}`}
      >
        Dismiss
      </button>
    </span>
  </li>
);

const SearchForm = ({ ... }) => (
  <form action={searchAction} className={styles.searchForm}>
    ...
    <button
      type="submit"
      disabled={!searchTerm}
      className={`${styles.button} ${styles.buttonLarge}`}
    >
      Submit
    </button>
  </form>
);

更方便的是小工具库 clsx（npm install clsx），它还支持按条件加类名：

src/App.jsx
import clsx from 'clsx';

// 组合
className={clsx(styles.button, styles.buttonLarge)}

// 条件：isLarge 为 true 时才加 buttonLarge
className={clsx(styles.button, { [styles.buttonLarge]: isLarge })}

{ [styles.buttonLarge]: isLarge } 里的方括号是 JavaScript 的计算属性名：用变量的值作为对象的键。 InputWithLabel 里的 label 和 input 也照此改成 styles.label、styles.input。

💡 全局样式放哪里

像 label、input 这种全站统一的基础样式，更适合放在全局的 index.css 里，而不是每个组件的 module 里各写一遍。 CSS Modules 负责“组件自己的样式”，全局 CSS 负责“全站基调”，两者可以共存。

小结

  • React 样式大致分为 CSS-in-CSS、CSS-in-JS、utility-first 三派；学习阶段可以都试试，项目里选一种。
  • 普通 CSS：import './App.css' + className；行内样式 style={{ … }} 适合动态值。
  • 普通 CSS 的类名是全局的，容易冲突；CSS Modules 通过 .module.css 让类名局部化。
  • 用模板字符串或 clsx 组合多个类名。原生 CSS 已支持嵌套，不一定需要 Sass。

动手练习

  1. 给 SearchForm 加一个 buttonClassName prop，让调用方决定用 button_small 还是 button_large。
  2. 改用 CSS Modules 后，打开开发者工具看看元素上的类名变成了什么样。
  3. 用 clsx 实现：列表中点数（points）大于 100 的文章标题加粗。
  4. 试试原生 CSS 嵌套：把 .item > span 写进 .item { … } 内部。

面试题

React 中给组件加样式有哪些方式？

全局 CSS + className、行内 style 对象、CSS Modules、Sass 等预处理器、CSS-in-JS（styled-components 等）、utility-first（Tailwind）以及 UI 组件库。

JSX 中的 style 属性和 HTML 有什么不同？

JSX 中 style 接收一个 JavaScript 对象，属性名用驼峰命名，数值默认单位为 px。

CSS Modules 解决了什么问题？

全局类名冲突。构建时为每个类生成唯一名称，使样式只作用于导入它的组件。

如何按条件组合多个 className？

用模板字符串、数组 join，或 clsx / classnames 等工具库：clsx('a', { b: cond })。
