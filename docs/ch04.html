第 4 章 · 组件与 JSX

JSX：在 JavaScript 里写界面

组件返回的那段“像 HTML 的东西”叫 JSX。它是 React 最有辨识度的特性： 不需要学一套新的模板语法，用一对花括号就能把任意 JavaScript 表达式塞进界面里。

本章目标

  • 用 { } 在 JSX 里显示变量、对象属性和函数返回值
  • 记住 JSX 和 HTML 的几处不同：className、htmlFor、驼峰命名、必须闭合
  • 理解 JSX 会被编译成普通的 JavaScript 函数调用
  • 知道 JSX 的几条规则：单一根元素、只能放表达式、注释写法

花括号：通往 JavaScript 的窗口

上一章留了一个问题：怎么把变量 title 显示出来？答案是用花括号：

src/App.jsx
const title = 'React';

function App() {
  return (
    <div>
      <h1>Hello {title}</h1>
    </div>
  );
}

export default App;

浏览器显示 “Hello React”。把 title 改成 'World' 并保存，页面立刻变成 “Hello World” —— 这就是上一章提到的热更新在起作用。

花括号里可以放任何表达式（能算出一个值的东西）：

JSX
const welcome = {
  greeting: 'Hey',
  title: 'React',
};

function getTitle(title) {
  return title;
}

function App() {
  return (
    <div>
      <h1>{welcome.greeting} {welcome.title}</h1>   {/* 对象属性 */}
      <h2>Hello {getTitle('React')}</h2>           {/* 函数调用 */}
      <p>1 + 1 = {1 + 1}</p>                          {/* 运算 */}
      <p>{'react'.toUpperCase()}</p>                  {/* 方法调用 */}
    </div>
  );
}
⚠ 只能放表达式，不能放语句

if、for、const x = 1 是语句，不能直接写进 { }。 需要条件判断时用三元运算符 cond ? a : b 或 cond && a（第 19 章）， 需要循环时用数组的 map()（下一章）。

JSX 不完全是 HTML

试着在 JSX 里加一个带标签的输入框。要求点击 “Search:” 文字时，输入框能获得焦点：

src/App.jsx
const title = 'React';

function App() {
  return (
    <div>
      <h1>Hello {title}</h1>

      <label htmlFor="search">Search: </label>
      <input id="search" type="text" />
    </div>
  );
}

注意 htmlFor：在 HTML 里它叫 for。JSX 本质上是 JavaScript， 而 for 和 class 是 JavaScript 的保留字，所以 React 换了名字。 最终渲染到浏览器时，它们会被还原成 for 和 class。

HTML 写法JSX 写法原因
class="card"className="card"class 是 JS 保留字
for="search"htmlFor="search"for 是 JS 保留字
onclick="..."onClick={fn}事件名用驼峰，值是函数而不是字符串
tabindex、maxlengthtabIndex、maxLength多单词属性一律驼峰
style="color: red; font-size: 14px"style={{ color: 'red', fontSize: 14 }}style 是对象，属性名驼峰
<br>、<img src="a.png"><br />、<img src="a.png" />所有标签都必须闭合
<!-- 注释 -->{/* 注释 */}注释要写在花括号里
aria-label、data-idaria-label、data-id例外：这两类保持短横线

属性值也可以用花括号动态指定：<a href={item.url}>、<img src={logo} />。 字符串字面量用引号，其他一切用花括号。

浏览器并不认识 JSX。Vite（背后是 Babel / esbuild / Oxc 这类编译器）会在代码送到浏览器之前， 把 JSX 翻译成普通的函数调用：

所以 JSX 不是必需的，你完全可以手写 createElement。 但几乎没人这么做：JSX 读起来就是界面的样子，而函数调用嵌套几层就没法看了。

经典转换 React ≤ 16
JSX
import React from 'react'; // 必须有，否则报错

// <h1>Hello</h1> 编译成：
React.createElement('h1', null, 'Hello');
自动转换 React 17+
JSX
// 不需要 import React

// <h1>Hello</h1> 编译成（编译器自动加 import）：
import { jsx as _jsx } from 'react/jsx-runtime';
_jsx('h1', { children: 'Hello' });
🔎 深入一点：HTML 和 JS 为什么要写在一起？

过去的“最佳实践”是把结构（HTML）、逻辑（JS）和样式（CSS）分到不同文件里。React 反其道而行： 按功能而不是按技术划分 —— 一个组件把和它有关的标记与逻辑放在一起。 因为按钮的外观和按钮被点击后做什么，本来就是紧密相关的。这个观点当年备受争议，现在已经被 Vue、Svelte、Solid 等框架以不同方式采纳。

JSX 的几条规则

1. 只能返回一个根元素

return 后面只能是一个元素。想并排返回两个？用一个父元素包起来， 或者用 Fragment <>…</>（第 16 章）：

❌ 报错
JSX
return (
  <h1>Hello</h1>
  <p>World</p>
);
✅ 正确
JSX
return (
  <div>
    <h1>Hello</h1>
    <p>World</p>
  </div>
);

原因看图 4-2 就明白了：JSX 会变成一个函数调用，而一个函数只能返回一个值。

2. 多行 JSX 用圆括号包起来

return ( 后面换行写 JSX 是惯例。如果写成 return 后直接换行， JavaScript 的自动分号插入会让函数返回 undefined。

3. 所有标签都要闭合

<input> 要写 <input />，<hr> 要写 <hr />。

4. 花括号里的值怎么显示

值显示结果
字符串、数字原样显示
true、false、null、undefined什么都不显示（条件渲染靠的就是这个）
数组依次显示每一项（列表渲染靠的就是这个）
JSX 元素渲染这个元素
普通对象 { a: 1 }报错：Objects are not valid as a React child
⚠ 安全：JSX 会自动转义

{'<script>alert(1)</script>'} 会被当成普通文字显示，而不会执行。 这让 React 默认就能防御大部分 XSS 攻击。如果你真的要插入一段 HTML 字符串，React 提供了一个名字很吓人的属性 dangerouslySetInnerHTML —— 名字就是在提醒你：只对完全可信的内容使用。

小结

  • JSX 让你在 JavaScript 里用类似 HTML 的语法描述界面；{ } 里放任意 JavaScript 表达式。
  • 属性名用驼峰：className、htmlFor、onClick；所有标签必须闭合。
  • JSX 会被编译成 jsx()（旧版是 React.createElement()）调用，返回描述界面的普通对象。
  • React 17 起，只写 JSX 的文件不再需要 import React。

面试题

什么是 JSX？浏览器能直接运行 JSX 吗？

JSX 是 JavaScript 的语法扩展，用类似 HTML 的写法描述 UI。浏览器不能直接运行，需要 Babel、esbuild 等工具编译成普通 JavaScript 函数调用。

使用 React 必须写 JSX 吗？

不必须。JSX 只是 createElement / jsx() 调用的语法糖，但它更直观，几乎所有项目都使用它。

为什么 JSX 中用 className 而不是 class？

JSX 最终是 JavaScript，class 是 JS 保留字，且 DOM 属性本身就叫 className。同理 for 写作 htmlFor。

为什么 React 17 之后不需要在每个文件里 import React？

新的 JSX 转换会让编译器从 react/jsx-runtime 自动导入所需函数，不再依赖作用域中的 React 变量。

JSX 里怎么写注释？

写在花括号里：{/* 注释 */}。
