第 48 章 · 生态与选型

常用工具库

除了状态、数据和 UI 这些“大块”，日常开发还会遇到一堆具体的小需求：表单校验、日期显示、多语言、动画、图表、长列表、拖拽、消息提示…… 每一类都有好几个候选库。这一章按需求逐类介绍主流选择、什么时候不需要库，并把它们用在 Hacker Stories 上。

本章目标

  • 了解表单、校验、日期、国际化、动画、图表等方向的主流库
  • 知道每一类“用浏览器内置能力就够了”的边界
  • 给 Hacker Stories 加上相对时间、多语言、删除动画和统计图表
  • 拿到一张“需求 → 推荐库”的速查表

表单与校验

第 41 章已经实际用过，这里做个横向比较：

表单特点适合
原生 form Actions（React 19）零依赖，useActionState + FormData简单表单、配合服务端函数

这些校验库大多实现了 Standard Schema 标准接口，React Hook Form、TanStack Form 等可以统一接入，换校验库的成本很低。

日期与时间

Hacker News API 返回的 created_at 是 ISO 字符串（如 2025-06-01T08:30:00.000Z）。 我们想显示成“3 小时前”。先看内置的 Intl 能做到什么程度：

src/format.js
const rtf = new Intl.RelativeTimeFormat('zh-CN', { numeric: 'auto' });

const UNITS = [
  ['year', 60 * 60 * 24 * 365],
  ['month', 60 * 60 * 24 * 30],
  ['day', 60 * 60 * 24],
  ['hour', 60 * 60],
  ['minute', 60],
];

const timeAgo = (isoString) => {
  const seconds = (new Date(isoString) - Date.now()) / 1000;

  for (const [unit, unitSeconds] of UNITS) {
    if (Math.abs(seconds) >= unitSeconds) {
      return rtf.format(Math.round(seconds / unitSeconds), unit);
    }
  }
  return rtf.format(Math.round(seconds), 'second');
};

timeAgo('2025-06-01T08:30:00.000Z'); // "3小时前" / "昨天" / "2个月前"

// 普通的日期格式化也不需要库
new Intl.DateTimeFormat('zh-CN', { dateStyle: 'medium' }).format(new Date());
// "2025年6月1日"

需要日期计算（加减、比较、区间、时区）时，再引入库：

date-fns：函数式、按需导入
JavaScript
import { formatDistanceToNow, addDays } from 'date-fns';
import { zhCN } from 'date-fns/locale';

formatDistanceToNow(new Date(story.created_at), {
  addSuffix: true,
  locale: zhCN,
}); // "大约 3 小时前"

addDays(new Date(), 7);
Day.js：moment 风格、2KB
JavaScript
import dayjs from 'dayjs';
import relativeTime from 'dayjs/plugin/relativeTime';
import 'dayjs/locale/zh-cn';

dayjs.extend(relativeTime);
dayjs.locale('zh-cn');

dayjs(story.created_at).fromNow(); // "3 小时前"
dayjs().add(7, 'day');
方案什么时候用
Intl（内置）只需要格式化显示（日期、相对时间、数字、货币）
date-fns日期计算多，喜欢纯函数、不可变
Day.js从 moment 迁移、喜欢链式 API、在意体积
Luxon时区处理复杂
moment❌ 维护模式，新项目不要用
ⓘ Temporal

JavaScript 正在引入新的日期时间 API Temporal，用来彻底取代设计糟糕的 Date，浏览器正陆续支持。 等它普及后，很多日期库都可能不再需要。

国际化（i18n）

让界面支持中英文切换。最流行的是 react-i18next：

命令行
npm install i18next react-i18next
src/i18n.js
import i18n from 'i18next';
import { initReactI18next } from 'react-i18next';

i18n.use(initReactI18next).init({
  lng: 'zh',
  fallbackLng: 'en',
  resources: {
    en: {
      translation: {
        title: 'My Hacker Stories',
        search: 'Search:',
        found: '{{count}} stories found',
      },
    },
    zh: {
      translation: {
        title: '我的 Hacker 新闻',
        search: '搜索：',
        found: '找到 {{count}} 篇文章',
      },
    },
  },
});

export { i18n };
src/App.jsx
import './i18n';
import { useTranslation } from 'react-i18next';

const App = () => {
  const { t, i18n } = useTranslation();

  return (
    <div>
      <h1>{t('title')}</h1>
      <p role="status">{t('found', { count: stories.length })}</p>

      <button onClick={() => i18n.changeLanguage(i18n.language === 'zh' ? 'en' : 'zh')}>
        中 / EN
      </button>
      ...
    </div>
  );
};

其他选择：FormatJS（react-intl）基于 ICU 消息格式，复数、性别等语法规则处理得更规范； Lingui 支持从代码中自动提取文案。使用 Next.js 时常用 next-intl。 实际项目里翻译文件通常放在单独的 JSON 文件中按需加载，并配合翻译平台管理。

动画

简单的 hover、展开收起，用 CSS transition 就够了。但有一种动画 CSS 很难做：元素被移除时的退出动画 —— 比如点 Dismiss 后文章淡出再消失。React 一删除元素它就立即从 DOM 中没了，来不及播放动画。 Motion（原名 Framer Motion）用 AnimatePresence 解决了这个问题：

命令行
npm install motion
src/App.jsx
import { AnimatePresence, motion } from 'motion/react';

const List = ({ list, onRemoveItem }) => (
  <ul>
    <AnimatePresence initial={false}>
      {list.map((item) => (
        <motion.li
          key={item.objectID}
          layout                                  // 其余项平滑补位
          initial={{ opacity: 0, y: -8 }}
          animate={{ opacity: 1, y: 0 }}
          exit={{ opacity: 0, x: 40 }}            // 被移除时向右淡出
          transition={{ duration: 0.2 }}
        >
          ...
        </motion.li>
      ))}
    </AnimatePresence>
  </ul>
);
💡 尊重“减少动态效果”设置

有些用户在系统里开启了“减少动态效果”（晕动症等原因）。CSS 用 @media (prefers-reduced-motion: reduce)， Motion 提供 useReducedMotion() 或全局的 MotionConfig reducedMotion="user"。

图表

给 Hacker Stories 加一张“当前搜索结果的点数分布”柱状图。Recharts 是最常用的 React 声明式图表库：

命令行
npm install recharts
src/PointsChart.jsx
import { BarChart, Bar, XAxis, YAxis, Tooltip, ResponsiveContainer } from 'recharts';

const PointsChart = ({ stories }) => {
  const data = stories.slice(0, 10).map((story) => ({
    name: story.title.slice(0, 12),
    points: story.points,
  }));

  return (
    <ResponsiveContainer width="100%" height={240}>
      <BarChart data={data}>
        <XAxis dataKey="name" />
        <YAxis />
        <Tooltip />
        <Bar dataKey="points" fill="#d95602" />
      </BarChart>
    </ResponsiveContainer>
  );
};
图表库特点适合
RechartsReact 组件式写法，基于 SVG，上手最快常规业务图表
ECharts（echarts-for-react）功能最强、图表类型最多、Canvas 渲染、中文文档完善大数据量、复杂可视化、数据大屏
Nivo默认样式漂亮，支持 SVG / Canvas展示型图表
Visx底层可视化积木（Airbnb）高度定制的可视化

小结

  • 表单：简单用原生 Actions，复杂用 React Hook Form；校验用 Zod（在意体积用 Valibot）。
  • 日期：显示用 Intl，计算用 date-fns 或 Day.js，不要再用 moment。
  • 国际化：react-i18next 最普及；需要规范的复数规则用 FormatJS。
  • 动画：简单的用 CSS，退出动画和布局动画用 Motion，注意减少动态效果设置。
  • 图表：常规用 Recharts，复杂和大数据量用 ECharts。
  • 长列表用虚拟滚动，复杂表格用 TanStack Table，拖拽用 dnd-kit。

面试题

为什么不再推荐 moment.js？

体积大且无法 tree-shake，API 是可变的（容易产生 bug），官方已进入维护模式。可以用 Intl、date-fns、Day.js 等替代。

在 React 中如何实现元素移除时的动画？

元素被移除时会立即从 DOM 删除，需要让它延迟卸载。可以使用 Motion 的 AnimatePresence 配合 exit 属性，或其他过渡库。

渲染上万条数据的列表会有什么问题？如何优化？

DOM 节点过多导致渲染和滚动卡顿、内存占用高。使用虚拟滚动（TanStack Virtual、react-window）只渲染可视区域内的行，或分页加载。

如何实现国际化？

使用 i18n 库管理多语言文案和当前语言，在组件中通过 t 函数等方式取文案；同时用 Intl 处理日期、数字、货币的本地化格式。
