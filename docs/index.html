React 是什么，一句话版

React 是一个用来构建用户界面的 JavaScript 库。它的核心思想只有一句： 界面是状态的函数 —— 你描述“在某种数据下，界面应该长什么样”， 数据一变，React 负责把页面更新成新的样子。你不再需要自己去找 DOM 节点、改文字、加删元素。

为什么强调“新版本”

React 从 2013 年发布到现在，写法已经变过好几轮。网上大量教程、博客、Stack Overflow 答案 还停留在旧写法上 —— 初学者最容易踩的坑，就是把不同年代的写法混在一起。下面这张时间线标出了 影响日常写法的几个关键版本：

🧩

函数组件 + Hooks

不再写类组件、不写 this、不写生命周期方法。状态用 useState，副作用用 useEffect。

🚀

createRoot

旧的 ReactDOM.render() 在 React 19 中已被移除，入口统一用 createRoot。

📝

Form Actions

<form action={fn}> 取代“onSubmit + preventDefault”，配合 useActionState 管理提交状态。

⚙️

React Compiler

编译器自动做记忆化，memo、useCallback、useMemo 不再需要到处手写。

这套教程写给谁

  • 学过一点 HTML / CSS / JavaScript，第一次接触 React的人。每个概念都从“为什么需要它”讲起。

ⓘ 需要什么前置知识

会写变量、函数、数组和对象就够了。map / filter、箭头函数、解构、展开运算符、 Promise 和 async/await 这些“现代 JavaScript”，用到的时候都会顺手讲一遍。 命令行只需要会 cd 和敲命令。

怎么用这套教程

  • 按顺序读，边读边敲。第 1–25 章是一条直线，后面的章节都依赖前面写好的代码。第 26 章以后的几部分（样式、维护、实战）相互独立，可以挑着读。
  • 留意这些标记： React 19 表示新版本特性； 旧写法 表示你在老代码里会见到、但现在不推荐的写法； 对照卡片左边是旧写法，右边是新写法。
  • 每章末尾有「动手练习」和「面试题」。练习题动手做，面试题先自己回答再展开看答案。
旧写法 React ≤ 17
JSX
import ReactDOM from 'react-dom';

ReactDOM.render(<App />, document.getElementById('root'));
新写法 React 18+ / 19
JSX
import { createRoot } from 'react-dom/client';

createRoot(document.getElementById('root')).render(<App />);

💡 一句话总结

如果你只记住一件事：React 组件就是一个函数，输入是 props 和 state，输出是界面描述（JSX）； 数据只从上往下流，想往上通知就传一个回调函数下去。 剩下的 37 章，都是在展开这句话。
