排序与反向排序

从这一部分开始，我们给 Hacker Stories 加上真实应用中常见的功能。每一节都以一个任务开头 —— 建议先自己尝试，卡住了再看提示和讲解。第一个任务：让列表可以按标题、作者、评论数、点数排序， 再次点击同一列时反向排序。

本章目标

  • 给列表加上表头，并用按钮切换排序依据
  • 用“排序函数字典”把排序键映射到排序逻辑
  • 基于上一次的状态计算新状态，实现正序 / 倒序切换
  • 避免在渲染中修改 props 数组
💡 任务一：排序

让列表可以按 title、author、comments、points 排序（先只实现一个方向）。提示：

  • 在 App 或 List 里新增一个 sort 状态；
  • 每一列一个按钮，点击时把 sort 设为这一列；
  • 根据 sort 对列表应用对应的排序函数；可以用 Lodash 的 sortBy。

先加表头

把列表当成一张表格：每行是一篇文章，每列是一个属性。先加一行表头，用行内样式简单地对齐：

src/App.jsx
const List = ({ list, onRemoveItem }) => (
  <ul>
    <li style={{ display: 'flex' }}>
      <span style={{ width: '40%' }}>Title</span>
      <span style={{ width: '30%' }}>Author</span>
      <span style={{ width: '10%' }}>Comments</span>
      <span style={{ width: '10%' }}>Points</span>
      <span style={{ width: '10%' }}>Actions</span>
    </li>

    {list.map((item) => (
      <Item key={item.objectID} item={item} onRemoveItem={onRemoveItem} />
    ))}
  </ul>
);

const Item = ({ item, onRemoveItem }) => (
  <li style={{ display: 'flex' }}>
    <span style={{ width: '40%' }}>
      <a href={item.url}>{item.title}</a>
    </span>
    <span style={{ width: '30%' }}>{item.author}</span>
    <span style={{ width: '10%' }}>{item.num_comments}</span>
    <span style={{ width: '10%' }}>{item.points}</span>
    <span style={{ width: '10%' }}>
      <button type="button" onClick={() => onRemoveItem(item)}>
        Dismiss
      </button>
    </span>
  </li>
);

排序状态放在哪里

只有 List 需要知道当前的排序方式，所以状态就放在 List 里（第 11 章：放在需要它的最近的组件）。 初始值 'NONE' 表示保持 API 返回的原始顺序：

src/App.jsx
const List = ({ list, onRemoveItem }) => {
  const [sort, setSort] = useState('NONE');

  const handleSort = (sortKey) => {
    setSort(sortKey);
  };

  return (
    <ul>
      <li>
        <span>
          <button type="button" onClick={() => handleSort('TITLE')}>
            Title
          </button>
        </span>
        <span>
          <button type="button" onClick={() => handleSort('AUTHOR')}>
            Author
          </button>
        </span>
        <span>
          <button type="button" onClick={() => handleSort('COMMENT')}>
            Comments
          </button>
        </span>
        <span>
          <button type="button" onClick={() => handleSort('POINT')}>
            Points
          </button>
        </span>
        <span>Actions</span>
      </li>

      {list.map((item) => ( ... ))}
    </ul>
  );
};

每个按钮用内联箭头函数（第 18 章）把自己的排序键传给 handleSort。

排序函数字典

JavaScript 的排序有不少坑（数字、大小写、undefined……），我们借助工具库 Lodash 的 sortBy：

命令行
npm install lodash
src/App.jsx
import { sortBy } from 'lodash';

然后定义一个对象，把每个排序键映射到一个“接收列表、返回排好序的新列表”的函数：

src/App.jsx
const SORTS = {
  NONE: (list) => list,
  TITLE: (list) => sortBy(list, 'title'),
  AUTHOR: (list) => sortBy(list, 'author'),
  COMMENT: (list) => sortBy(list, 'num_comments').reverse(),
  POINT: (list) => sortBy(list, 'points').reverse(),
};

评论数和点数用 .reverse()，是为了让数字从大到小排 —— 看热门文章时，大家更想先看点数高的。 在 List 里取出当前的排序函数，先排序，再渲染：

src/App.jsx
const List = ({ list, onRemoveItem }) => {
  const [sort, setSort] = useState('NONE');

  const handleSort = (sortKey) => {
    setSort(sortKey);
  };

  const sortFunction = SORTS[sort];
  const sortedList = sortFunction(list);

  return (
    <ul>
      ...

      {sortedList.map((item) => (
        <Item key={item.objectID} item={item} onRemoveItem={onRemoveItem} />
      ))}
    </ul>
  );
};
⚠ 不要用 list.sort()

数组自带的 sort() 和 reverse() 会原地修改数组。list 是 props， 直接修改它就等于篡改了父组件的状态（第 9 章：props 只读）。Lodash 的 sortBy 返回新数组，所以对它的结果调用 .reverse() 是安全的。 如果不想引入 Lodash，ES2023 新增的 toSorted()、toReversed() 会返回新数组： list.toSorted((a, b) => b.points - a.points)。

任务二：反向排序

💡 任务二

同一个按钮点第二次时，改为反方向排序；再点一次又恢复。提示：再加一个状态 isReverse； 在 handleSort 里根据上一次的排序状态计算新状态。

“排序键”和“是否反转”总是一起变化，把它们放进同一个对象状态里：

src/App.jsx
const List = ({ list, onRemoveItem }) => {
  const [sort, setSort] = useState({
    sortKey: 'NONE',
    isReverse: false,
  });

  const handleSort = (sortKey) => {
    const isReverse = sort.sortKey === sortKey && !sort.isReverse;

    setSort({ sortKey, isReverse });
  };

  const sortFunction = SORTS[sort.sortKey];
  const sortedList = sort.isReverse
    ? sortFunction(list).reverse()
    : sortFunction(list);

  return ( ... );
};

关键是这一行：sort.sortKey === sortKey && !sort.isReverse。 只有“点的还是同一列”并且“当前不是反向”时，新状态才是反向；换了一列，一律从正向开始。

对象属性简写

setSort({ sortKey, isReverse }) 用了 ES6 的属性简写：属性名和变量名相同时，可以只写一次。

JavaScript
const firstName = 'Robin';

const user = {
  firstName: firstName,
};

// 等价于
const user2 = {
  firstName,
};

小结

  • 排序状态只保存“键”（和方向），排好序的列表在渲染时派生出来 —— 不要把排序结果存成状态。
  • 用字典对象把排序键映射到排序函数，比一长串 if/else 更清晰、易扩展。
  • 不要原地修改 props 数组；用 Lodash sortBy 或 toSorted() 返回新数组。
  • 新状态依赖旧状态时，在处理函数里基于当前状态计算（或用 setSort(prev => …) 的函数形式）。

面试题

在 React 中对列表排序时要注意什么？

不要原地修改 props 或 state 中的数组（sort、reverse 会修改原数组）；应生成新数组，并且排序结果通常在渲染时派生，而不是存成状态。

为什么排序状态可以放在 List 而不是 App 中？各有什么影响？

只有 List 使用它，就近放置更内聚；但 List 卸载（例如加载中被替换）时状态会丢失。放在 App 中可以跨加载保留，但 App 会承担更多职责。

当新状态依赖于旧状态时应该怎么做？

基于旧状态计算新值；如果可能在同一次事件中多次更新，使用 setter 的函数形式 setX(prev => …) 以获取最新值。
