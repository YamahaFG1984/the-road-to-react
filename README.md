# React 19 入门教程（The Road to React 学习版）

基于《The Road to React》（Robin Wieruch）整理的 37 章中文图解教程，全部代码使用 React 19 写法，并对照说明旧版本的做法。

- 在线阅读：部署 `docs/` 目录到 GitHub Pages 即可（Settings → Pages → Deploy from a branch → `main` / `/docs`）。
- 源文件：`docs-src/`（HTML 片段，代码块用 ``` 围栏书写，无需手动转义）。
- 生成：修改源文件后运行 `python3 tools/build.py`，会重新生成 `docs/` 下的所有页面和 `docs/assets/chapters.js`。
- 样式与脚本：`docs/assets/style.css`、`docs/assets/site.js`（侧边栏、目录、复制按钮、深浅色切换）。
